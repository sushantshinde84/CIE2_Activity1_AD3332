## 1. Objective

To implement Multiple Linear Regression for predicting a continuous target variable using multiple numerical input features.

## 2. Dataset Information

- **Dataset:** Diabetes Dataset
- **Source:** Scikit-learn
- **Total Records:** 442
- **Input Features:** 10 numerical features
- **Target Variable:** Target (disease progression measure)

Dataset source: https://scikit-learn.org/stable/datasets/toy_dataset.html#diabetes-dataset

## 3. Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels

## 4. Activities Performed

1. Loaded and inspected the dataset.
2. Checked missing values and duplicate records.
3. Created scatter plots and a correlation heatmap.
4. Performed manual least-squares calculations using two features.
5. Verified manual calculations using Scikit-learn.
6. Implemented Simple Linear Regression and Multiple Linear Regression.
7. Split the dataset into 80% training and 20% testing data.
8. Evaluated models using MAE, MSE, RMSE, R² and Adjusted R².
9. Performed residual analysis.
10. Checked multicollinearity using Variance Inflation Factor (VIF).
11. Examined Multiple Linear Regression assumptions.
12. Predicted a new target value.
13. Prepared a decision log and final conclusion.

## 5. Model Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R-squared (R²)
- Adjusted R-squared

## 6. Conclusion

Multiple Linear Regression was implemented successfully using the Scikit-learn Diabetes dataset. Manual calculations were compared with the library implementation. Simple and Multiple Linear Regression models were evaluated, and residual and multicollinearity analyses were performed.
